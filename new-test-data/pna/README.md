## Test datasets origin

This test data is generated by Pixelgen Technologies AB for the nf-core/pixelator pipeline.

Synthetic PNA test data in this folder was generated with internal prototype scripts.

### FASTQ generation procedure

Data generation used deterministic seeds for reproducibility.

Generation was performed in two steps:

1. Build a synthetic edgelist parquet with:

- 20 cells
- 600 nodes per cell
- 22200 edges in total (200 crossing edges)
- 20% of antibodies are hashing antibodies

2. Convert each parquets into paired FASTQ files and using the corresponding PNA panel definitions:

- proxiome-v1-immuno-155-v1.1 panel for `sample1`, `sample1_reseq`, `sample2`
- proxiome-v2-immuno-155-prerelease panel for `pool1`, `pool1_reseq`, `pool2`

This generates the files in `testdata/pna/fastq`, including:

- `sample1*_R1.fastq.gz`, `sample1*_R2.fastq.gz`, `sample2_R1.fastq.gz`, `sample2_R2.fastq.gz`
- `pool1*_R1.fastq.gz`, `pool1*_R2.fastq.gz`, `pool2_R1.fastq.gz`, `pool2_R2.fastq.gz`
- corresponding `*.metadata.json` files

Single-end versions of `sample1`, `sample1_reseq`, `sample2`, `pool1`, `pool1_reseq` and `pool2` are also provided as
`<library>_single_end_forward.fastq.gz` and `<library>_single_end_reverse.fastq.gz` (each with `*.metadata.json`).
Each read covers the whole amplicon: as is in the forward file, reverse-complemented in the reverse file.
Both are drawn from the library's edge list with the same seed, so each read in the reverse file is the reverse complement
of the matching read in the forward file.
They were generated separately from the paired-end files, with the Pixelator test data generator
(`uv run python -m pixelator.testing.test_data`), so they do not share edge lists with the paired-end files.

The samplesheets `samplesheet_proxiome_v1.csv` and `samplesheet_proxiome_v2.csv` in `new-test-data/samplesheet/pna/` each hold
four units (samples for v1, pools for v2): two resequenced (`sample_1` / `pool1` and their `_forward` counterparts) and two
single-end (`*_forward`, forward read in `fastq_1`).

The samplesheets `samplesheet_proxiome_v1_single_end.csv` and `samplesheet_proxiome_v2_single_end.csv` hold the same units,
plus `*_reverse` units that pass the reverse files as the reverse read. They have a `reverse_read` column: `yes` for the
`*_reverse` rows, `no` or empty for the `*_forward` rows, and empty for the paired-end rows.

### Module output generation (`testdata/pna/modules`)

Module artifacts were then generated with Pixelator `single-cell-pna` subcommands, in this order:

1. `amplicon`
2. `demux`
3. `collapse` + `combine-collapse`
4. `graph`
5. `denoise` (pool-level for proxiome-v2)
6. `sample-calling`
7. `layout`
8. `analysis`

Representative options (from module metadata):

- `demux`: `--design proxiome-v2 --panel proxiome-v2-immuno-155-prerelease`
- `sample-calling`: `--samplesheet samplesheet_proxiome_v2.csv --enrichment-threshold 10.0`
- `graph`: `--component-size-min-threshold 100 --multiplet-recovery`
- `layout`: `--layout-algorithm coarsened_pmds_3d`
- `analysis`: `--compute-proximity --proximity-nbr-of-permutations 100`
