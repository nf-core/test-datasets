# nft-utils test data

Test data for the nf-test plugin [nf-core/nft-utils](https://github.com/nf-core/nft-utils).

## Files

- `extract/tbzip2_archive`: a bzip2-compressed tar archive without a file extension, for `extract(..., compression: "tbzip2")`. It holds `archive/a.txt` and `archive/sub/b.txt`.
